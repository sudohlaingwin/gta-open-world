Why this file is here: Godot 4.3's built-in default font contains
NO Myanmar-script glyphs (proven live: Font.has_char() is false
for every Myanmar codepoint tested). The Slice 69 signboards
therefore cannot use the default font — they use this real
Myanmar font, and the Slice 69 sim verifies every codepoint of
every sign text against it before the build is accepted.
